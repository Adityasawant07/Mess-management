# 🍽️ Mess Management System

A mobile-based Mess Management System built using **React Native (Expo) and Firebase** to simplify mess operations, meal tracking, student management, and mess fee monitoring.

The application provides separate interfaces for students and mess vendors, making mess management more organized, transparent, and convenient.

## 🚀 Features

### 👨‍🎓 Student Panel
- Student registration and login.
- View weekly mess menu.
- Mark meal attendance for breakfast, lunch, and dinner.
- View individual meal details and pricing.
- Track remaining mess balance.
- Monitor meal consumption and expenses.

### 👨‍🍳 Vendor Panel
- Vendor registration and login.
- Manage registered students.
- Create and update weekly mess menus.
- Set prices for individual meals.
- Monitor student meal attendance.
- Track student balances and mess transactions.

## 📱 Application Overview

The application follows a role-based approach:

- **Students:** Access their mess information, weekly menu, meal tracking, and remaining balance.
- **Vendors:** Manage menus, meal prices, student records, and mess operations.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Adityasawant07/Mess-management.git
```

### 2. Navigate to the project directory

```bash
cd Mess-management
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the Expo development server

```bash
npx expo start
```

You can run the application using Expo Go or an Android development environment.

## 🎯 Project Objective

The objective of this project is to replace traditional manual mess management with a digital solution that improves transparency, reduces manual record-keeping, and makes meal and payment tracking easier for both students and vendors.
